# Kakan

Kakan is a Flutter application for user authentication using OTP-based login, built with clean architecture and BLoC state management.

## Features
- OTP-based login with phone number verification.
- User profile creation with username and email.
- Secure token storage using `flutter_secure_storage`.
- Network requests with Dio and automatic token refresh.

## Setup Instructions

### Prerequisites
- Flutter SDK: >=3.0.0
- Dart: >=2.17.0
- IDE: VS Code or Android Studio
